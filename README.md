# Big Ballers Gazette

The weekly newspaper of the Big Ballers fantasy football league — live at https://djmed900.github.io/

**Home** (`index.html`) — season overview: live standings pulled from the Sleeper API on every visit, season superlatives, the latest edition, Week 7 matchups on deck, and live national NFL headlines from ESPN.

**Editions**
- `week-6/` — Week 6, Trash-Talk Tabloid edition: "The Perfect Season Is Dead"
- `week-5/` — Week 5 full paper
- `week-4/` — Week 4 full paper (trash-talk edition)
- `week-3/` — Week 3 full paper

Each edition is a single self-contained HTML file. A new week = a new `week-N/index.html` folder plus a link update on the home page.

Future home: bigballersgazette.news (a `CNAME` file gets added here once that domain is registered — don't add it before then, or GitHub will stop serving the github.io address).
